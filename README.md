# Active ONA: инструкция

Этот небольшой проект строит граф рабочих связей сотрудников по результатам Active Organizational Network Analysis (ONA).

## 1. Файлы проекта

- `build_active_ona_graph.py` — скрипт, который строит графики.
- `active_ona_edges_3cols.csv` — исходная таблица связей.
- `ona_graphs/` — папка, в которую скрипт сохраняет изображения.

## 2. Как должна выглядеть база

CSV-файл должен содержать ровно три обязательных столбца:

| respondent_email | target_email | relationship_type |
|---|---|---|
| anna@example.com | ivan@example.com | Экспертный совет |
| anna@example.com | petr@example.com | Решение сложной проблемы |
| ivan@example.com | anna@example.com | Рабочее взаимодействие |

**Что означают столбцы:**

- `respondent_email` — сотрудник, который отвечает на опрос и указывает коллегу.
- `target_email` — коллега, которого он выбрал.
- `relationship_type` — тип связи из соответствующего вопроса опросника.

Одна строка = один выбор коллеги по одному вопросу. Один и тот же респондент может повторяться в нескольких строках. Это нормально.

Названия столбцов должны совпадать с указанными выше. Кодировку CSV рекомендуется использовать UTF-8.

## 3. Установка

Нужен установленный Python. Откройте терминал в папке проекта и выполните:

```bash
python -m pip install pandas networkx matplotlib
```

Если в вашей системе команда Python называется `py`, можно выполнить:

```bash
py -m pip install pandas networkx matplotlib
```

## 4. Запуск

Убедитесь, что скрипт и CSV лежат в одной папке. Запустите:

```bash
python build_active_ona_graph.py
```

Или в Windows:

```bash
py build_active_ona_graph.py
```

После запуска появится папка `ona_graphs`.

## 5. Какие графики создаются

- `ona_network_combined.png` — все типы связей вместе.
- `ona_network_advice.png` — экспертный совет.
- `ona_network_problem_solving.png` — помощь в решении сложных проблем.
- `ona_network_work.png` — регулярное рабочее взаимодействие.
- `ona_network_information.png` — источник важной информации.

Если в CSV присутствует только часть типов связей, графики будут построены только для них.

## 6. Как читать граф

- **Узел** — сотрудник. На схеме отображается часть email до знака `@`.
- **Стрелка** — направление выбора: от респондента к указанному коллеге.
- **Цвет линии** в общем графе — тип связи.
- **Размер узла** — число входящих выборов в конкретном графе. В общем графе это число разных сотрудников, которые указали данного человека хотя бы по одному типу связи; в отдельном графе — по соответствующему типу связи.

Большой узел — это сигнал высокой входящей связанности, но сам по себе он не доказывает наличие формального авторитета, высокой эффективности или неформального лидерства. Результаты важно интерпретировать с учетом цели опроса, охвата респондентов и организационного контекста.

## 7. Что скрипт проверяет

Перед построением графа скрипт:
- проверяет наличие обязательных столбцов;
- убирает пробелы и пустые строки;
- приводит email к нижнему регистру;
- исключает строки, где респондент указал самого себя.

Если файл не найден или обязательных столбцов нет, скрипт выдаст понятное сообщение об ошибке.

## 8. Как изменить цвета

В начале `build_active_ona_graph.py` есть словарь `COLORS`. В нём можно изменить цвет каждого типа связи. Если добавить новый тип связи, скрипт всё равно построит его граф, но для него будет использован серый цвет, если отдельный цвет не задан.
